# LEARN: LLM Engineering Learning Journey

This repository documents my 8-week learning journey through **Ed Donner's LLM Engineering course on Udemy**.
It is designed so that other learners can follow the same path, reuse the exercises, and adapt the structure for their own learning.

---

## 1. Learning Goals

By working through this repo, I aim to:

- Build a solid mental model of how modern Large Language Models (LLMs) work
- Practice prompt engineering and evaluation in a systematic way
- Learn how to fine-tune and adapt LLMs for specific tasks
- Build small but realistic LLM-powered applications and tools
- Develop good engineering practices around version control, testing, and documentation for LLM projects

This is a **work-in-progress learning space**, not a polished product.

---

## 2. Repository Structure

The repo is organized by week to mirror the 8‑week plan from the course.
Each `week-*` folder contains notes, experiments, and code for that stage of the journey.

- `week-1/` – Foundations, setup, and first experiments
- `week-2/` – Working with prompts, tokens, and model behavior
- `week-3/` – Building simple LLM-powered scripts and utilities
- `week-4/` – Improving reliability: evaluation, iteration, and debugging
- `week-5/` – Integrations, APIs, and more advanced workflows
- `week-6/` – (Planned) Fine-tuning, adapters, and customizing models
- `week-7/` – (Planned) Larger applications, pipelines, and agents
- `week-8/` – (Planned) Capstone, consolidation, and next steps

Folders for weeks 6–8 may be empty or evolving as I progress.

---

## 3. How to Use This Repo as a Learner

If you want to learn along with me:

1. **Start with `README.md`** to understand the high-level goals.
2. Work through the `week-1` folder first, reading any notes and running the code.
3. Move to the next week only after you feel comfortable with the previous material.
4. Treat each week as a mini-project: read, experiment, break things, and take your own notes.
5. Adapt or extend the exercises to match your interests or tools (e.g., different LLM providers or frameworks).

You do *not* need access to the exact same Udemy course to benefit from this repo, but it is structured around that course.

---

## 4. Recommended Prerequisites

You will get the most out of this repo if you have:

- Basic programming experience (Python and/or JavaScript/TypeScript is helpful)
- Familiarity with Git and GitHub
- Curiosity about how LLMs work and how to use them responsibly

Having access to at least one LLM API (e.g., OpenAI, Anthropic, etc.) will help you run many of the exercises.

---

## 5. Workflow and Practices

I use this repo to practice good engineering habits while learning:

- Keeping changes small and frequent
- Writing simple, clear code and notes instead of aiming for perfection
- Using branches and commits to track my progress over time
- Documenting what I tried, what worked, and what didn’t

Feel free to fork this repo and make it your own learning log.

---

## 6. How This Fits GitHub Education Community Exchange

This repository is intended to be **reusable by other students and educators**:

- It shows a realistic, incremental learning journey through LLM engineering.
- The week-by-week structure makes it easy to plug into a course, club, or study group.
- Each folder can be used as a template for assignments, lab sessions, or self-study.

If you are an educator, you can:

- Clone or fork this repo and adapt the weekly structure to your syllabus.
- Add your own exercises, readings, and assessments on top of the existing weeks.
- Encourage students to maintain their own LEARN.md or learning logs.
